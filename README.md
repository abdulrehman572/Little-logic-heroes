# Little Logic Heroes

> An interactive educational mobile application designed to help young children develop early learning, logical thinking, memory, pattern recognition, and problem-solving skills through playful activities.

---

## Overview

**Little Logic Heroes** is an interactive educational mobile application built to make early childhood learning more engaging, interactive, and fun.

The application combines game-based learning with educational activities to help children develop important cognitive and foundational learning skills.

Children can explore activities related to:

* Shapes
* Counting & Numbers
* Patterns
* Logic
* Memory
* Puzzles
* Alphabet Learning

The application is designed with a child-friendly interface, animations, speech feedback, and interactive elements to create an enjoyable learning experience.

## Application Architecture

```text
App
│
├── Navigation
│
├── Screens
│
├── Components
│
├── Services
│
├── Hooks
│
├── Store
│
├── Modules
│
├── Utils
│
└── Theme
```

### Architecture Overview

* **Navigation** — Handles application navigation and screen transitions.
* **Screens** — Contains the main application screens.
* **Components** — Reusable UI components.
* **Services** — Application-level services and functionality.
* **Hooks** — Custom React hooks.
* **Store** — Application state and local state management.
* **Modules** — Educational activities and learning modules.
* **Utils** — Helper functions and utilities.
* **Theme** — Centralized styling, colors, typography, and visual configuration.

## Getting Started

### Prerequisites

Make sure the following are installed on your system:

* Node.js
* npm
* Expo development environment
* Android Studio (for Android development)

---

## Installation

Clone the repository:

```bash
git clone https://github.com/abdulrehman572/Little-logic-heroes.git
```

Navigate to the project directory:

```bash
cd Little-logic-heroes
```

Install dependencies:

```bash
npm install
```

---

## Running the Application

### Start Development Server

```bash
npm start
```

### Run on Android

```bash
npm run android
```

### Run on Web

```bash
npm run web
```
